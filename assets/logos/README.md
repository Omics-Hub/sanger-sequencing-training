# Logos

This folder is a placeholder for the organisational logos to display at the
top of the training README (e.g. in a banner or side-by-side header).

I haven't downloaded or embedded the actual logo image files here, since
both organisations publish brand/usage guidelines that should be checked
before redistributing their marks:

- **The Company of Biologists** — corporate branding info:
  https://www.biologists.com/about-us/corporate-branding/
- **CSIR-IIR (Council for Scientific and Industrial Research – Institute of
  Industrial Research)** — about page:
  https://www.csir-iir.com/pages/about.html

**To finish this section:**
1. Download the appropriate logo file(s) from the pages above, respecting
   whatever usage/attribution terms they specify.
2. Save them here as e.g. `company-of-biologists-logo.png` and
   `csir-iir-logo.png`.
3. Reference them in the main `README.md` banner, e.g.:
   ```markdown
   <p align="center">
     <img src="assets/logos/csir-iir-logo.png" height="60">
     &nbsp;&nbsp;&nbsp;
     <img src="assets/logos/company-of-biologists-logo.png" height="60">
   </p>
   ```
